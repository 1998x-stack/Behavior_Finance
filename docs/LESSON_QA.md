## 自动化检查

`scripts/check_lessons.py` 使用标准库检查唯一 H1、重复 ID、课程导航、相对路径资源、同页锚点、旧模板残留；对模块 04 额外核查 Markdown 全段落出现在 HTML 可见文字、图注与 SVG 的可访问描述。

`scripts/browser_qa.py` 使用 Playwright 在 Chromium 中对 20 篇课程做 360、390、768、1440 px 的离线访问（80 组页面检查）；核查页面横向溢出、JS pageerror、H1 数量、三项章节导航及样式表装载；为 360/1440 px 保存每课截图，并上传到 GitHub Actions 工件，供人工复核。

运行时依赖 Playwright + Chromium；CI 的浏览器任务固定 `ubuntu-24.04`，避免 GitHub 默认 runner 更新时的平台兼容性问题。

## 来源与版权边界

课程目录及概念映射参照仓库的 `docs/PDF_CONTENT_MAP.md` 和《陆蓉行为金融学讲义》（中信出版集团，2019）。本轮无法重新逐页检查原始 PDF，因此没有杜撰准确页码。文中案例为原创教学假设；研究论文以作者、年份、标题标注，不声称假设数据源自论文。

## 验收边界

通过静态测试不等于浏览器视觉验收通过；通过浏览器自动化也不代表截图已逐张进行人工设计审查；GitHub PR 创建不等于 Pages 已部署。详情以对应 GitHub Actions 执行结果、工件及合并状态为准。
