# 行为金融学 · Behavioral Finance Learning Hub

> 从心理学理解金融决策，从行为偏差理解市场现象，再用可检验的框架分析投资问题。

本仓库围绕行为金融学的核心问题组织课程：人如何形成信念、如何做出选择、这些偏差如何影响交易与资产价格，以及我们如何避免错误并评估行为投资策略。内容以课程笔记、原创解释、可视化专题和可复现实验为主。

## 内容地图

### 原理：心理学如何进入金融决策
- 认知（belief）：信息收集、信息加工、信息输出与反馈。
- 决策（preference）：参考点依赖、损失厌恶、风险态度、概率加权、狭隘框架、心理账户与博弈思维。

### 应用：从个体偏差到市场现象
- 投资者常见错误：分散化不足、简单分散化、过度交易、处置效应、买入偏差与羊群效应。
- 市场与资产定价：大盘可预测性、股权溢价、价量关系、Miller 假说与博傻理论。
- 行为策略：规模与价值溢价、动量与反转、财务信息与组合构建。

### 实战：用机制而不是口号分析案例
案例页应明确区分历史事实、理论解释、可检验假设和个人判断；不把历史案例写成当前投资建议，也不把回测或模拟结果等同于未来收益。

## 页面设计原则

每个专题页都是一篇完整、独立、自足的教学文章。读者即使没有读过其他页面、没有打开原始 PDF，也必须能够从问题背景、术语定义、必要前置知识、形成机制、完整案例、金融含义、适用边界一路读到总结。正文直接解释知识本身，不写成“讲义介绍了什么”“作者指出什么”的资料转述，也不把理解所必需的上下文推给上一页或外部链接。

采用渐进式讲解，而非堆砌概念：问题与直觉 → 概念定义 → 机制图解 → 理论模型 → 完整案例 → 交互探索 → 适用边界 → 实践清单 → 参考资料。不同主题选择适合的表达方式：前景理论使用价值函数与交互实验；羊群效应使用群体决策模拟；价量关系使用供需和交易机制图；行为投资策略使用组合收益与风险分析。

**Agent 编辑规范：**开始任何页面改造前，先阅读 [AGENTS.md](AGENTS.md)。它规定了独立成篇、来源核验、写作禁区、页面验收和发布流程。

视觉参考采用 [Olah-style-posts](https://github.com/1998x-stack/Olah-style-posts) 的渐进式叙事与图解教学方法；所有文章文字、图形和示例独立编写，不复制其文章资产。

## 研究与教学边界

- 行为偏差是可检验的机制假说，不是对每个投资者的心理诊断。
- 相关性不等于因果；模拟数据不等于真实市场证据。
- 策略回测必须披露样本区间、基准、交易成本、风险暴露和潜在偏差。
- 市场异象可能随制度、参与者和交易成本变化，不承诺持续超额收益。
- 本项目用于学习与研究，不构成个性化投资建议。
